# JavaScript Store Menu

A small browser-based JavaScript exercise modelling a store menu with drinks, snacks, and meals.

## What it demonstrates

- Functions, arrays, conditional branches, and user input.
- Item selection through browser prompts and feedback in the console.

## Run

Open a browser developer console on a blank local page and run the contents of [commerce.js](commerce.js). Follow the prompt dialogs and read the console messages. The script uses the browser's `prompt()`; it does not run unchanged in Node.js.

## Scope

This is a learning exercise, not a checkout system. The current implementation selects items but does not calculate prices or a payment total, persist a cart, or process payments.

## Next improvements

Add a persistent cart model, numeric input validation, prices and totals, and tests for invalid selections.
